# The fine print

Onside is a skill based prediction game. Match results decide outcomes, the eight final-table tickets split the jackpot with half of it going to the champion, and everyone else's entry stays in the pot they played for.

$ONSIDE is a token with a job inside this game. Nothing in these docs is financial advice, an offer of securities, or a promise that any number goes up. The flywheel describes routing, not returns.

The game runs on public blockchains and live football. Chains congest, oracles lag, and matches get postponed; we route around what we can and tell you when we cannot.

**Never play with more than you can afford.**
