# Start here

## What this is

Onside is a survivor game played across all 104 matches of the 2026 World Cup. You enter with a $10 ticket, you call a score for every match, and good calls earn points that push your ticket up one shared board. At six checkpoints a line rises from the bottom and everyone under it is out. The last cut leaves a final table of eight tickets, and the final table splits the entire jackpot: half of it to the champion, every seat in the money.

These docs are the breakdown of the whole machine: every rule, every fee, every split, and every burn. If a number is on these pages, it is the number in the code.

## The numbers that matter

| | |
| --- | --- |
| **$10** | per ticket, USDC or SOL |
| **90%** | of every entry feeds the pot |
| **104** | matches to survive |
| **8** | paid seats, the champion takes half the pot |

{% hint style="warning" %}
**One rule above all:** money in this game moves in one direction, into the jackpot or out of supply. Nothing on these pages is a promise of profit; it is a description of routing.
{% endhint %}

## How these docs are laid out

* **The game** covers playing: the loop, tickets, the board, and the line.
* **The economy** covers spending: packs and Boosts, the marketplace, and what $ONSIDE actually does.
* **The ledger** is the trust section: the routing table for every fee, how the jackpot number is computed, and the fine print.
